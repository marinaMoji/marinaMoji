marinaMoji est installé et a été enregistré auprès de macOS.

S'il n'apparaît pas dans Réglages Système → Clavier → Sources d'entrée, déconnectez-vous puis reconnectez-vous une fois, puis ajoutez-le.

macOS peut accepter l'enregistrement alors que la session de connexion actuelle cache encore la source d'entrée ; une déconnexion reconstruit cette liste.
