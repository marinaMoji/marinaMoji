marinaMoji apt repository

Debian/Ubuntu packages for marinaMoji in two channels: stable (final releases only) and unstable (every release, including release candidates).

Install

curl -fsSL https://marinamoji.github.io/marinaMoji/marinaMoji-release-public-key.asc \
  | sudo gpg --dearmor --yes -o /usr/share/keyrings/marinamoji-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/marinamoji-archive-keyring.gpg] https://marinamoji.github.io/marinaMoji stable main" \
  | sudo tee /etc/apt/sources.list.d/marinamoji.list

sudo apt update
sudo apt install marinamoji
ibus restart

To follow release candidates too, use unstable instead of stable in the deb line.
